# dengchaogjp-notes

Cloud engineer · AWS and CDK · archiving old docs

处理日常小任务的工具

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。

## 安装

```bash
git clone https://github.com/USER/dengchaogjp-notes.git
cd dengchaogjp-notes
cargo build --release
```
